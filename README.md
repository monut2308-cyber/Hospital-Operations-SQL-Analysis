# 🏥 Hospital Operations & Healthcare Analytics (SQL)

## 📌 Project Overview
An exploratory SQL data analysis project examining hospital capacity, patient admissions, length of stay, and medical expenditure across multiple cities and departments using **PostgreSQL**.

## 🛠️ SQL Techniques Used
- **Aggregations & Grouping:** `SUM()`, `AVG()`, `ROUND()`, `GROUP BY`
- **Date & Time Analysis:** `EXTRACT()`, `TO_CHAR()`, Date Interval Subtraction (`discharge_date - admission_date`)
- **Filtering & Ranking:** `ORDER BY`, `LIMIT`, `NULLIF()`
